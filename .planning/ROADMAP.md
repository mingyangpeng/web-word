# v1.0 Roadmap

## Phase 1: 设计系统基础

**Goal:** 建立统一的视觉设计系统，为所有后续改动提供一致的基础。

**Requirements:**
- DESIGN-01: 统一的视觉设计系统
- DESIGN-02: 响应式布局适配
- DESIGN-03: 可访问性优化

**Success Criteria:**
1. 用户可以切换浅色/深色主题（实现 DESIGN-01）
2. 布局在不同屏幕尺寸下正常工作（实现 DESIGN-02）
3. 文字对比度符合 WCAG AA 标准（实现 DESIGN-03）
4. 创建样式指南文档，记录所有设计规范

**Planned Work:**
- 定义颜色系统（主色调、辅助色、背景色）
- 定义字体系统（字体族、大小、行高）
- 定义间距系统（4px/8px/16px/24px/32px）
- 创建可复用的 Streamlit 组件（按钮、卡片、输入框）
- 实现主题切换功能

**Acceptance Test:**
- 在两个主题下打开应用，视觉一致性良好
- 在 1920px、1366px、768px、375px 屏幕尺寸下测试
- 使用色彩对比度检查工具验证对比度

**Plans:**
- [x] 01-01-PLAN.md — Design system foundation

## Phase 2: 主内容区重新设计

**Goal:** 重新设计动词输入和释义展示的核心区域。

**Requirements:**
- UI-01: 重新设计动词输入区域
- UI-02: 优化释义对比展示
- UI-03: 改进语义分解表格的展示方式
- UI-04: 添加动词示例库

**Success Criteria:**
1. 搜索框有更好的视觉焦点和交互效果（UI-01）
2. 释义对比区域有清晰的视觉层次和动画效果（UI-02）
3. 语义分解表格更加美观易读（UI-03）
4. 用户可以从示例库快速选择动词（UI-04）

**Planned Work:**
- 改进搜索框样式和交互（自动补全、快捷键）
- 设计释义对比区域的卡片布局
- 重新设计语义分解表格（使用 emoji、图标或不同背景色）
- 创建动词示例库组件（快速选择常用动词）
- 实现 Google 风格固定搜索栏和实时搜索（300ms 防抖）

**Acceptance Test:**
- 输入动词后，释义展示区域立即响应且视觉美观
- 可以点击示例库中的动词快速填充
- 语义分解表格在两种主题下都清晰可读

**Plans:**
- [x] 02-01-PLAN.md — Google 风格搜索栏与实时搜索 ✅
- [x] 02-02-PLAN.md — 卡片式释义展示与示例库 ✅

## Phase 5: 多视图设计

**Goal:** 实现视图切换功能，支持不同的使用场景。

**Requirements:**
- UI-12: 实现视图切换（释义视图、分析视图、设置视图）
- UI-13: 使用标签页切换不同动词
- UI-14: 添加历史记录视图
- UI-15: 实现比较视图

**Success Criteria:**
1. 用户可以在多个视图间切换（UI-12）
2. 标签页切换不同动词流畅（UI-13）
3. 历史记录视图显示之前的查询（UI-14）
4. 比较视图并排显示多个动词释义（UI-15）

**Planned Work:**
- 实现视图切换器（Tabs）
- 创建释义视图、分析视图、设置视图
- 实现动词标签页功能
- 添加历史记录视图（从 session_state 或本地存储）
- 创建比较视图（选择多个动词并排对比）

**Acceptance Test:**
- 视图切换动画流畅
- 标签页切换无延迟
- 比较视图清晰展示多个动词的差异
