<task type="auto">
  <name>Task 2: 实现释义展示</name>
  <files>src/app.py</files>
  <action>
    显示动词的中文释义和语义分解。

    语义分解要素：
    - 【方式】- 动作采用的姿势/手段（如：用眼睛看、用耳朵听）
    - 【方向】- 动作朝向的目标（如：朝向前方、向上）
    - 【体相】- 动作时的身体姿态（如：睁大眼睛、身体前倾）
    - 【范围】- 动作涉及的范围/程度（如：只看局部、看完全程）

    展示方式：
    - 使用表格展示，每个要素一行
    - 使用 emoji 图标标记：🚶 (方式), 🛤️ (方向), 🎯 (体相), 💪 (范围)
    - 使用设计系统颜色编码（如：背景色区分不同要素）

    内容来源：初期使用 mock 数据，后续接入 LLM API
