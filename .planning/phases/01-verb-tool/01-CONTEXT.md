# Phase 1: 设计系统基础 - 上下文

## Domain

建立统一的视觉设计系统，为所有后续改动提供一致的基础。

**Phase 范围:**
- 设计系统基础（颜色、字体、间距、组件样式）
- 响应式布局（桌面端优先，极简策略）
- 可访问性基础（WCAG AA）
- 不包括具体功能实现（在后续阶段）

---

来自 ROADMAP.md:

### DESIGN-01: 统一的视觉设计系统
**目标:** 建立统一的设计规范

**边界:**

**目标:** 适配不同屏幕尺寸

**边界:**

**目标:** 确保基本可访问性

**边界:**

**约束:**
- 不追求 AAA 级别可访问性
- 优先考虑代码简洁性和可维护性

## Decisions

### 配色方案

**选择:** 白色为主，蓝灰色系，简约学术风格

**理由:**
- 匹配应用的教育/学术定位
- 白色背景 + 蓝灰色主色 (#4a5568) 清晰专业
- 高对比度，易读性好
- 符合用户"简约学术风格"偏好

**颜色规范:**
```
主色 (Primary): #4a5568 (蓝灰色)
辅助色 (Secondary): #63b3ed (浅蓝)
成功色 (Success): #48bb78 (绿色)
警告色 (Warning): #ed8936 (橙色)
错误色 (Error): #f56565 (红色)
背景 (Background): #ffffff (白色)
卡片 (Card): #f8fafc (极浅灰)
文本 (Text): #1a202c (深灰)
次级文本 (Secondary Text): #718096 (中灰)
边框 (Border): #e2e8f0 (浅灰)
```

### 响应式断点策略

**选择:** 极简响应式（仅桌面端 Chrome 优化）

**理由:**
- 目标用户在桌面端 Chrome 浏览器
- 减少开发复杂度
- 利用 Streamlit 原生响应式功能
- 保持代码简洁

**策略:**
- 使用 `st.set_page_config(layout="wide")`
- 依赖 Streamlit 自动列堆叠
- 关键断点: 1200px（列布局调整点）

### 可访问性优先级

**选择:** 基础遵循 WCAG AA

**理由:**
- 符合一般可访问性标准
- Streamlit 默认元素已满足大部分要求
- 避免过度优化增加复杂度
- 优先实现核心功能

**实施标准:**
- 文字对比度 ≥ 4.5:1
- 所有交互元素支持 Tab 键导航
- 使用语义化 HTML 标签
- 表单元素有明确标签

### 主题切换

**选择:** 无主题切换（固定浅色主题）

**理由:**
- 简化实现复杂度
- 符合"简约学术风格"定位
- 白色背景在学术/教育场景更合适
- 减少用户认知负担

**已放弃的选项:**
- Streamlit 原生 `st.set_theme()` API
- 自定义主题系统
- 深色模式支持

## Codebase Context

**现有代码结构:**
- `src/app.py` - 单文件实现（所有样式和逻辑混在一起）
- 当前使用 Streamlit 原生组件和内联 CSS
- 无外部设计系统依赖

**可复用资产:**
- 无外部 CSS/主题文件
- Streamlit 原生组件（按钮、输入框、表格等）
- 内联 `<style>` 标签用于搜索栏固定

**集成点:**
- `app.py` 第 20-35 行: 搜索栏内联样式
- `app.py` 第 83-141 行: MOCK_DEFINITIONS 数据结构
- `app.py` 第 153-184 行: 侧边栏组件
- `app.py` 第 188-403 行: 主区域组件

**约束:**
- Streamlit 不支持 SASS/SCSS
- 无服务端模板系统
- 颜色和样式通过 Python 变量 + Streamlit 主题系统管理
- 无法使用 Tailwind/Vue/React 等现代前端框架

## Specifics

**技术实现细节:**

1. **颜色变量定义**
   - 在 `app.py` 顶部定义全局颜色常量
   - 所有 UI 元素引用这些常量
   - 便于统一调整配色

2. **间距系统**
   - 基础单位: 8px
   - 使用: 8px, 16px, 24px, 32px
   - 间距类函数（可选）

3. **字体系统**
   - 主字体: 系统默认无衬线字体
   - 标题: 略大，加粗
   - 正文: 16px 行高 1.6
   - 代码: 等宽字体

4. **组件样式**
   - 按钮: 圆角 8px，hover 效果
   - 输入框: 圆角 8px，focus 边框
   - 卡片: 白色背景，轻微阴影
   - 表格: 清晰边框，斑马纹

5. **响应式策略**
   - 桌面端 (>1200px): `st.columns([3, 7])`
   - 中等尺寸 (768-1200px): `st.columns([2, 8])`
   - 小尺寸 (<768px): 自动堆叠为单列

## Deferred Ideas

## Noted for Later
