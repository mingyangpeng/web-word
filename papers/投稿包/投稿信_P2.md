意象图式的归属判定长期依赖研究者内省，图式标签因此多为不可复核的理论断言。本文以 Sketch Engine 的 enTenTen21 语料库 word sketch 搭配证据为底座（136 个方式聚焦移动动词、50,751 行搭配明细），报告一条「图式×槽位映射—重心指数—候选初筛—噪声治理—义位四选一标注」的完整提取流程，主要贡献有三：

1. **图式的语料可证性标准**：提出「槽位覆盖×语义同质×释义回验」三信号叠加判据，使图式从内省标签变为逐条可核查、可回溯到原始 JSON 的语料对象，对 Lakoff—Johnson 内省传统是补证而非替代；
2. **偏斜分布的方法论论证**：词目层初筛 118/10/7/1 的极端偏斜与 tear（同形混杂）、sweep（隐喻用法）、ferry（伪互动）三个噪声案例的逐层证据链，证明「统计簇不等于语言学义位类」；
3. **共享图式作为中间表征层**：35 个路径／互动词目的捞回使源点脱离、终点抵达、互动位移三类图式获得真实词元，四图式范畴体系方能成立；共享图式上承义位准入判定、下启「域—系」范畴体系，并直接支撑学习词典的释义优化与例句选择。
