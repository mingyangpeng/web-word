# 01 数据来源与检索流程

> 本系列方法文档共五份，按编号阅读：01 数据来源与检索流程 → 02 槽位说明 → 03 意象图式提取说明 → 04 logDice 与原型性得分说明 → 05 义位标注规范。
> 本文说明语料数据的来源、检索参数与可回溯性。

## 1. 语料库与检索平台

| 项目 | 内容 |
|---|---|
| 语料库 | English Web 2021 (enTenTen21)，约 61 亿词的网络英语语料 |
| 检索平台 | Sketch Engine（广外图书馆 libVPN 代理访问，订阅版） |
| 检索工具 | Word Sketch（词汇 Sketch Engine 自动归纳的语法关系搭配列） |
| 检索接口 | `bonito/run.cgi/wsketch`（结构化 JSON 返回） |
| 检索日期 | 2026-09-30 |

选择 enTenTen21 的理由：规模最大（网络英语，覆盖通用与专业语域）、经词性标注与句法依存解析、Sketch Engine 原生支持 Word Sketch 与 logDice，且为开题报告原型性量化流程（logDice、Word Sketch 槽位）的直接适配语料。

## 2. 词表来源

136 个动词取自项目《词表义项清单.xlsx》「词表概览」页（Levin 1993 自移移动动词筛选后收窄的自移移动词表），主范畴含方式聚焦型等，次类含奔跑行进类、常态行走类、运载工具类等。清单文件：`04_汇总统计/verbs_136.json`。

## 3. 检索参数

```
corpname = preloaded/ententen21_tt31
lpos     = -v                # 动词词性（见 3.1 回退说明）
maxitems = 50                # 每槽位取前 50 个搭配词
minfreq  = auto              # 频次下限自动
minscore = 0                 # 不做搭配强度预筛（保留全部证据面）
clustercolls = 0; minsim = 0.15; sort_gramrels = 1; sort_ws_columns = s
structured = 1               # 含主题分布（High）等结构化字段
```

**3.1 词性回退**：kayak、skateboard、backpack 三词在 enTenTen21 中动词用法 sketch 不存在（API 返回 "Lemma not found"），回退为不限词性（实际为名词主导，`lpos=-n` 或空）。汇总表已标注实际词性。后续义位分析时，此三词动词用法的语料证据较弱，需在判定中注明。

**3.2 两轮检索的关系**：

| 轮次 | maxitems | 存放位置 | 用途 |
|---|---|---|---|
| 第一轮 | 15 | `04_汇总统计/wordsketch_summary.json`（汇总） | 快速总览、跨词对比 |
| 第二轮 | 50 | `03_语料搭配/`（逐词 xlsx）、`05_原始数据/`（逐词 JSON） | 正式分析档案，语义归类在 50 条口径下进行 |

两轮 API 参数除 maxitems 外完全一致；如需复现开题报告"前 15"口径，取搭配明细表前 15 行即可。

## 4. 数据规模

| 指标 | 数值 |
|---|---|
| 动词数 | 136 |
| 义位数（OALD10 逐义项） | 669（132 词 665 + 4 词补充 4） |
| 语料总频次跨度 | scutter 391 ～ run 24,647,035 |
| 槽位数（每词） | 3 ～ 28 个语法关系列 |
| 原始 JSON 总量 | 136 文件，约 15 MB |

## 5. 可回溯性设计

1. **原始层**：`05_原始数据/wsketch_full/<动词>.json` 保存每词 API 原始返回，任何 xlsx 数值均可回溯至此；
2. **处理层**：`03_语料搭配/<动词>.xlsx` 为唯一人工写入点（搭配明细表 I/J 两列：语义类别、保留/剔除），其余全部为 API 原始数据直出；
3. **义位层**：`02_义位标注/<动词>_义项.xlsx` 的释义、例句均注明来源（OALD10 / oxford-cache / levin-brief），判定依据可回溯。

## 6. 生成脚本（可重复运行）

| 脚本 | 产出 |
|---|---|
| `scripts/export_verb_corpus_sheets.py` | 逐词语料档案 xlsx（03_语料搭配） |
| `scripts/export_sense_annotation_sheets.py` | 逐词义位标注表 xlsx（02_义位标注） |

数据源更新后重跑脚本即可再生成；人工填写的语义归类列重跑会覆盖，请在数据定稿后再运行或先备份。
