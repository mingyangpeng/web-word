# 05 义位标注规范

> 本文规定义位（sense）层面的分析单元、编号体系、14 字段规范与标注流程。
> 理论依据：`docs/义项判定标准修改稿.docx`（四条标准全文）；逐词标注表见 `02_义位标注/`。

## 1. 分析单元：义位而非词目

**SenseID = <动词>-S<序号>**，如 walk-S1 … walk-S24。

- 样本池取自 Levin (1993) 自移移动动词清单，但分析单元严格限定为**义位（sense）**而非词目（lemma），以规避一词多义带来的词目层分类偏差；
- 同一词目下可同时存在 Y 原型义与拓展隐喻义，必须拆分为独立义位分别标注；
- 后续所有环节——准入判定、图式标注、对齐等级、PS 计算、语料清洗——均以 SenseID 为单元。

## 4. 四条判定标准（摘要）

> 全文见《义项判定标准修改稿.docx》；此处为操作摘要。

### 标准 1 义位准入（Y / 拓展 / N）

- **Y**：义位描写实体运动体，发生真实三维物理空间位置变化，可构建源点-路径-终点位移框架；
- **拓展**：动词形为移动动词，但无实体物理运动体，空间位移图式投射至抽象域（chase a dream）；
- **N**：静态方位义（无空间移动）或纯状态变化义（仅内在属性改变）；被标 N 的义位不删除，完整保存剔除理由；
- **简易口诀**：有没有真实物理实体在三维空间从一个位置移动至另一位置？有→Y；抽象隐喻投射→拓展；无位移仅方位/属性改变→N；
- **边界**：原地振动/局部摆动 → N；瞬时坠落、使役自移（有整体空间位移）→ Y；存疑案例统一归入争议清单仲裁。

### 标准 2 意象图式（仅 Y、拓展填写）

四选一（源点脱离 / 终点抵达 / 方式伴随 / 互动位移）；依据动词义位本身编码的语义重心，不纳入句子状语附加信息；不得自行新增图式类型。操作方法见《03 意象图式提取说明》。

### 标准 3 原型层级

Y = 原型物理位移义（进入范畴聚类、释义模板构建）；拓展 = 隐喻引申边缘义（仅用于语义辐射网络与英汉隐喻对比，不进入核心统计）。

### 标准 4 英汉图式对齐（Y 完整填写；拓展简要；N 跳过）

- **完全对齐**：英汉激活相同图式，核心构件全部保留；
- **部分对齐**（最常见）：图式大体一致但要素不匹配（英语内置方式、汉语需副词增补；英语内置路径、汉语强制趋向补语）；
- **零对齐**：汉语不启用空间位移框架；配套记录汉语句法特征与译义转化策略。

## 5. 标注流程与信度控制

```
输入：SenseID + OALD 释义 + 真实语料例句 2–3 条 + 逐词语料档案（03_语料搭配）
  │
  ├─ AI 辅助初筛：生成候选标签（Y/拓展/N、候选图式、候选对齐等级）——仅为参考
  │
  ├─ 人工分层复核：
  │    AI 标 Y → 重点核查是否混淆隐喻-字面义
  │    AI 标 N → 逐条复核剔除理由是否匹配静态方位/纯状态变化定义
  │    边界存疑 → 全部深度研判，进仲裁清单
  │
  └─ 信度：随机抽 15%–20% 第二编码人独立标注，算 Kappa；
          无第二编码人则 10–14 天重测，报告重测一致性
```

归档要求：全部义位（Y/拓展/N）完整保存；备注栏记录判定依据与争议点；AI 初标与人工判定不一致处写入备注。

## 6. 与语料数据的配合

同一动词的全部义位共享该词的 Word Sketch 语料数据（`03_语料搭配/<动词>.xlsx`），判定顺序：

```
先读义位（释义+例句，02_义位标注）
   → 查图式证据槽位（verb_sheets「图式证据」表）
   → 按 SenseID 的语义类别做概念归类清洗（搭配明细 I/J 列）
   → 填准入标签（标准1）+ 意象图式（标准2）
   → Y 类义位进入 PS 计算与范畴聚类
```

**注意**：义位准入在先、PS 在后（理由见《04 logDice 与原型性得分说明》第 3 节）；同一词内不同义位共用语料面，义位级清洗以 SenseID 的语义类别为归属依据。
