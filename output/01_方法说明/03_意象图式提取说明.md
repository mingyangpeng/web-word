# 03 意象图式提取说明

> 本文说明四类意象图式（源点脱离 / 终点抵达 / 方式伴随 / 互动位移）如何从语料数据中提取与判定。
> 前置阅读：《02 槽位说明》（槽位定义与边界）；logDice 数值含义见《04 logDice 与原型性得分说明》。

## 1. 核心原理：图式不在语料里，语料里只有分布

意象图式是认知表征，语料库中可直接观察的只有**搭配分布**——哪个槽位被什么词填、频次多高、搭配强度多大。所谓"从语料提取图式"，是在 Talmy 位移事件框架的桥接下，把分布证据翻译为认知范畴：

- **理论桥接**：图式 = 位移事件要素（Theme / Source / Goal / Path / Manner / 互动关系）的凸显构型。四类图式即四种要素凸显方式（《义项判定标准修改稿》标准 2）；
- **分工**：语料回答"哪个要素在该动词的使用档案里信号最强、最同质"；词典释义回答"该要素是否为动词自编码"。**两个信号叠加才产生图式标签**，任何单一信号都不足以上升为结论。

## 2. 四步操作法

### 2.1 第一步：槽位 → 事件要素证据面

| 图式（语义重心） | 证据槽位 | 理由 |
|---|---|---|
| 源点脱离 | particles after（away/off/out）；objects of "%w off/out/away"；from/out of 类 PP | away/off/out 是英语编码"离开源点"路径的专职小品词，其宾语即被脱离物 |
| 终点抵达 | objects of "%w"；objects of "%w up/down/in/into"；to/at/in 类 PP；particles after with object | GOAL 在及物动词落为宾语（reach the summit），不及物动词落为趋向 PP（arrive at） |
| 方式伴随 | modifiers（方式状语）；adjectives after；"%w" and/or ...（并列同类方式动词）；subjects（典型运动体）；usage patterns；complements | 方式不改变论元结构，落在状语与同类方式动词并列；主语给出运动体类型 |
| 互动位移 | objects / pronominal objects；pronominal subjects；after/behind 类 PP；particles after with object | 互动必有第二实体，落为宾语或追踪/伴随介词补足语 |

**注意（槽位重合是设计使然）**：objects 与 prepositional phrases 同时列在"终点抵达"与"互动位移"下，subjects 同时列在"方式伴随"与"互动位移"下。同一搭配面在不同义位下激活不同图式（reach the summit 是终点，follow him 是互动）。映射表给的是"去哪找证据"，不是"证据指向哪个图式"。

此映射已逐词落地于每词 xlsx 的「图式证据」工作表（空缺槽位 = 该图式证据面缺失），并按 136 词聚合于《图式证据总览.xlsx》。

### 2.2 第二步：搭配词语义归类（人机分工接口）

同一 Goal 证据，station（空间终点）激活空间位移图式，conclusion（抽象结果）不激活。以开题报告"到达类"的清洗标准为例：

- **保留**：能明确指代可被物理到达的三维空间实体的搭配词（destination, airport, station, summit, shore…）；
- **剔除**：①抽象概念名词（conclusion, agreement, goal, level）；②隐喻投射名词（milestone, threshold——词源为空间、共时已高度隐喻化）；③量化/时间/状态名词（number, time, speed）。

操作位置：每词 xlsx「搭配明细」表 **I 列（语义类别）**与 **J 列（保留/剔除）**；剔除记录完整保留并写明理由（方法透明度要求）。

### 2.3 第三步：重心计算

两个指标：

1. **纯净度**：某图式一致搭配词占槽位前 15/50 的比例；
2. **强度×广度**：一致搭配词的 logDice 均值 × 数量（PS 公式构件，见 04 文档）。

**判定规则**：

- 某图式的证据面**既覆盖主要槽位、搭配词又语义同质** → 该图式凸显；
- 证据面**缺失**或搭配词**语义发散** → 该图式非重心。

### 2.4 第四步：释义回验（动词自编码 vs 句法增补）

《修改稿》标准 2 硬约束：**依据动词义位本身编码的语义重心判定，不纳入句子状语带来的附加语义**。

- limp：释义 "to walk with difficulty because one leg is injured"——跛行方式在词根内 → 方式伴随；
- walk：释义 "move on foot"——方式（用脚）在词根内，Goal 不在论元结构 → 方式伴随；
- 若某要素只出现在附加语槽（状语/PP），无论多高频，都不能判定为动词自编码。

语料回答"要素多常见"，释义回答"要素是否动词自带"——两者叠加定标签。

## 3. 完整实例

### 3.1 walk（本套语料真实数据）

| 槽位 | 前 5 搭配词 | 归类 |
|---|---|---|
| subjects | man, dog, woman, girl, guy, people（minute/min/hour/mile 为 "minutes' walk" 名词构式噪声，剔除） | Theme 全为有生移动者，强且同质 |
| modifiers | slowly, barefoot, alone, briskly, backwards | Manner 强且同质 |
| objects | distance, tour, trail, mile | 名词化用法（a walking tour），非动词的 Goal 论元 |
| PP | into(3.9), to(3.8), in(3.74) | 路径靠可选介词短语增补，动词本体不带 |

归纳：方式与运动体信号内嵌且同质，Goal 依赖外部增补且不进入论元结构；释义 "move on foot" 印证 → **方式伴随图式**。

### 3.2 arrive / reach（开题报告数据）

| 指标 | arrive | reach |
|---|---|---|
| 核心槽位 | X at ... + X in ...（数据断层+功能验证确立） | objects of X |
| 空间终点纯净度 | 80%（at）/ 87%（in） | 约 20%（仅 height, peak, destination, top） |
| 有效搭配词 N | 60 | 25 |
| Mean logDice | 7.291 | 6.459 |
| PS | 43.23（原型成员） | 30.36（典型成员，垂直维度终点为显著次类） |

两词图式相同（终点抵达），**槽位剖面完全不同**——纯净度与 PS 的落差就是"图式锚定强度"与"原型地位"的语料提取结果。对比演示了：原型成员语义高度集中（锚定范畴核心图式），边缘成员语义发散（大量使用事件偏离核心认知域），符合原型范畴理论的预测。

## 4. 图式重心指数（量化方案，可选）

PS 回答范畴层"谁最典型"；同一公式换个方向可回答动词层"该词凸显哪个图式"：

```
S(图式) = Σ over 该图式证据槽位 ( 语义归类=一致的搭配词数 ) × 平均 logDice
```

- 取 **argmax** 为凸显图式；次高记入备注（对应 14 字段规范"多重图式取凸显重心，次要图式记入备注"）；
- **前提**：先完成语义归类（I/J 列）；严格义位级提取须按 SenseID 筛出与目标义位一致的搭配词再算（Word Sketch 为词目层数据，多义动词如 run 的计算机义搭配会稀释图式信号）。

## 5. 局限与边界

1. **指数与纯净度是证据不是结论**：最终图式标签必须能被释义+例句回溯（《修改稿》可回溯性要求）；边界案例（原地振动/局部摆动 → N；瞬时坠落/使役位移有整体位移 → Y）进争议清单人工仲裁；
2. **词目层混合**：Word Sketch 不做词义消歧，多义词的搭配跨义位聚合；义位级判定必须配合 sense_sheets 的义位准入结果使用；
3. **AI 定位**：本套数据的槽位映射、聚合统计均属"AI 辅助初筛"性质；按《修改稿》，全部最终标签由研究者人工逐条复核，AI 输出仅为候选参考。
