## 一、理论基础（完善版）

### 1.1 理论定位：图式范畴化统摄框架

MOVECAT 不是新的释义理论，而是**图式-多维释义模板的数字化载体**。统摄框架由四个理论支柱构成，每个支柱推导出一组可操作的平台功能：

| 理论支柱 | 核心命题 | 平台上的操作化 |
|---|---|---|
| Talmy 移动事件理论 | 位移事件 = Figure + Ground + Path + Manner（+Cause）；真正的物理移动必须存在实体的空间位置改变 | 五维标注之**维度 1（准入标签）**：Y/拓展/N 三分，静态方位与纯状态变化被排除在样本外 |
| 意象图式理论 | 位移事件的认知语义由有限的图式构型组织；动词义位凸显不同图式重心 | 五维标注之**维度 2（意象图式）**：四选一，取凸显重心 |
| 原型范畴理论 | 范畴以原型为核心向外辐射，成员地位不平等 | **准入三分 + 原型层级**：Y 类内部再按语料证据排原型梯度（PS 得分） |
| 认知对比语言学（图式映射） | 跨语言对比的对象是概念化方式（图式），不是词对词的翻译 | 五维标注之**维度 3（英汉对齐）**与**维度 4/5（句法特征、译义策略）** |

### 1.2 四类图式的封闭性理据（理论完善点）

《义项判定标准修改稿》给出四类图式但未论证"为什么恰好是四类、不可新增"。补足如下：

动词词根在位移事件中能**编码**的语义重心，按 Talmy 的事件要素分解只有四种可能：

1. **SOURCE 凸显** → 源点脱离图式（leave, depart 类）：词根编码"移出原点"的路径段；
2. **GOAL 凸显** → 终点抵达图式（arrive, reach 类）：词根编码"到达终点"的路径段；
3. **MANNER 凸显** → 方式伴随图式（run, swim, limp 类）：词根编码与位移**同时**的方式共事件（co-event），路径留待句法增补；
4. **第二移动体凸显** → 互动位移图式（chase, follow, accompany 类）：事件框架内出现两个位移体，词根编码二者间的空间互动关系（追踪/伴随/规避）。

四者穷尽了 Levin (1993) 自移动词类的词汇化模式：路径要素的两端（源/的）、路径之外的方式共事件、以及事件框架扩容（双移动体）。**封闭性的验证口径**：若某义位四类均无法涵盖，即触发 `needs_review`（存疑仲裁），而不是现场发明第五类——这一约束保证范畴体系的可证伪性与可比性。

**凸显重心判定规则**（防止句子信息污染动词义位）：只看动词词根自编码的语义重心，不纳入句子状语的附加信息。limp 的"跛行"在词根内 → 方式伴随；walk 虽高频伴随方式状语，但"用脚"之义在词根内、路径依赖介词短语增补 → 仍为方式伴随；arrive 的终点不在词根论元结构内、必须由 at/in 增补 → 按 Talmy 的卫星框架框架记为终点凸显（配角化路径）。

### 1.3 义位观：统计簇 ≠ 语言学义位（理论完善点）

平台的**分析单元是义位（SenseID = 动词-Sn）**，不是词目，也不是统计聚类簇。三者的关系：

```
词目（lemma）            统计簇（logDice 聚类）         义位（SenseID）
编纂单位，多义混杂    ≠    搭配相似例句的集合，      ≠   词典学分析单元，
                          有噪音、低频义位识别弱         可回溯、可标注、可质控
                └──────── 人工词典学校验（合并/拆分/剔除）────────┘
```

候选义位的起点是 OALD10 词典义项（`oald_senses` 表，132 词 665 条）——理由：词典义项已经是编纂者经验判断的义位切分，以其为起点做人工校验（而非从零聚类），把人工精力集中在"校验"而非"发现"。LogDice 搭配簇的角色由此明确：**义位判定的旁证**（某义项的搭配剖面是否与其释义一致），而非义位来源。

### 1.4 证据分层模型（理论完善点）

平台把判定证据分为三层，权重递减、回溯性递增：

| 层级 | 证据 | 在平台中的呈现 | 判定权重 |
|---|---|---|---|
| L1 内省层 | OALD 释义 + 词典例句 | 义位卡片的释义/语法码/例句区 | **主证**：准入与图式标签首先依据释义可否激活位移框架 |
| L2 使用层 | enTenTen21 语料分布（槽位剖面、纯净度） | 语料证据条 + 语料数据集页 | 旁证：与主证冲突时进存疑清单 |
| L3 计量层 | logDice、重心得分 S、PS | 四图式得分表、PS 计算表 | 排序依据：同类义位/成员间的梯度排序 |

这一分层直接落实《义项判定标准修改稿》"判定仅基于释义+例句，语料作为可回溯佐证"的约定，也回应审稿人最可能的质疑——**量化指标不替代语义判断，只承担成员排序与证据可视化**。

### 1.5 原型性的量化操作化

```
PS = Mean_logDice × log2(N + 1)
```

- 理论来源：Rosch (1978) "原型成员拥有最多与范畴相关的特征" → 特征数 N（搭配词型数）× 特征权重（logDice 均值）；借鉴王欢、林正军 (2022) 显著共现词项分析与 Divjak & Gries (2006) 质量-广度双维度框架；
- 图式重心指数（同族公式）：`S(图式) = 一致搭配词数 × Mean_logDice`，argmax 为候选凸显图式；
- **计算时点约定**：先义位准入（定性）→ 概念归类清洗（语义标准）→ PS 在清洗后集合上计算（定量）；筛选前纯净度另行报告。

### 1.6 信度理论：Krippendorff's α 与迭代质控

- 选 α 而非 Cohen's κ：α 支持**多值类别**（准入三分、图式四选一）、容忍**缺失数据**（重叠标注不必全覆盖）、对小样本稳健——与义位标注的数据形态完全匹配；
- 迭代逻辑：试标注 → 分歧定位（按维度统计分歧率）→ 修订标注手册 → 再标注 → α 复算；平台以 `needs_review` 字段承载分歧案例的仲裁流转；
- 报告口径：分维度报告 α（准入、图式、对齐各一个值），而非笼统总体一致性。

## 二、平台框架设计

### 2.1 设计原则

1. **理论先行**：每个模块对应一项词典学任务，不实现任何无语言学任务对应的功能；
2. **最小闭环**：语料导入 → 候选义位 → 五维标注 → 质控导出，四环相扣即为完整原型，多者不做；
3. **全程可回溯**：任一标注可回溯到 释义+例句（L1）与 语料原始 JSON（L2/L3）；
4. **人机分工**：AI 只做初筛（候选图式、得分排序），最终标签人工判定；边界案例强制走存疑仲裁。

### 2.6 质控设计

1. **信度**：随机抽 15%–20% 义位由第二编码人独立标注（平台当前为单标注人视图，v2 增加"标注人"字段与重叠分派）；无第二编码人则 10–14 天重测；
2. **一致性**：分维度计算 Krippendorff's α（准入/图式/对齐），分歧条目按维度归因（隐喻-字面边界、Cause 维度、图式重心之争）；
3. **仲裁**：needs_review=1 的义位构成仲裁清单，双人讨论后定标，全程留存判定理由；
4. **可回溯**：标注依据 = L1 释义例句（页面同屏）+ L2/L3 语料（corpus_* 表 + wsketch_full 原始 JSON）。

### 2.7 与现有工具对比（论文 §5 素材）

| 能力 | TLex / Lexonomy（商业 DWS） | Inception / BRAT（NLP 标注） | MOVECAT（本研究） |
|---|---|---|---|
| 出版级词条编辑与导出 | ✓ 完整 | ✗ | ✗（刻意不做） |
| 聚类候选义位导入与人工校验 | ✗ | 部分（例句标注） | ✓ 义位级管理 |
| 移动事件图式五维标注 | ✗（无语言学定制） | 需自行配置且非释义导向 | ✓ 内置四图式+准入+对齐 |
| 语料搭配证据同屏（logDice） | ✗ | ✗ | ✓（Word Sketch 直连） |
| IAA 迭代质控 | ✗ | ✓（通用） | ✓（面向标注手册迭代） |

防护句（照 1003 大纲）：MOVECAT 是研究原型，在通用编纂功能上弱于成熟商业 DWS；对比仅围绕"候选义位导入—图式五维标注—IAA 质控"这一面向释义的任务链展开。

### 2.8 边界声明（论文 §1.4/§6 口径）

1. 产出是**词典学研究标注资源**，不是面向普通读者的成品词典；
2. MOVECAT 是**研究型标注原型**，非传统 DWS，不具备词条编辑、多用户管理、辞书出版导出；
3. 136 词原始语料已批量入库，但**仅试点子集走完人工标注全流程**（论文以 10–12 动词试点呈现），大规模标注留给博士论文；
4. 词间语义关系标注仅预留接口（word_relations 表与词簇交互图），本项目未开展词-词关系的人工标注。
