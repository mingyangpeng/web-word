## 2. 三层数据结构

```
┌─────────────────────────────────────────────────────────────┐
│ 义位层（02_义位标注）      分析单元：SenseID                  │
│   释义 + 例句 + 及物性 + 人工标注区（图式/准入/理由/备注）      │
├─────────────────────────────────────────────────────────────┤
│ 语料证据层（03_语料搭配）   证据单元：槽位×搭配词              │
│   槽位 → 事件要素证据面；搭配词 → 语义归类 → 保留/剔除 → PS    │
├─────────────────────────────────────────────────────────────┤
│ 原始层（05_原始数据）       Sketch Engine API 原始返回         │
│   任何 xlsx 数值均可回溯至此                                  │
└─────────────────────────────────────────────────────────────┘
```

同一动词的义位与语料的对应：`02_义位标注/walk_义项.xlsx` ↔ `03_语料搭配/walk.xlsx`（同名配对）。

## 3. 阅读顺序

**第一次接触本包**：

1. 本 README → 2. `00_数据集说明与数据字典.md`（数据集怎么建、每个文件每个字段是什么） → 3. `01_方法说明/01_数据来源与检索流程.md` → 4. `02_义位标注/义位标注索引.xlsx`（总表） → 5. 任选一词对照读两份文件（推荐 walk：`walk_义项.xlsx` + `walk.xlsx`） → 6. `01_方法说明/` 其余四份按编号读。

**开始标注**：应用侧栏「🏷️ 标注平台」（在线表单）+ `01_方法说明/05_义位标注规范.md`（规范）+ `03_语料搭配/<动词>.xlsx`（证据）+ `01_方法说明/03_意象图式提取说明.md`（图式判定方法）+ `06_图式提取结果/图式提取结果汇总.xlsx`（AI 初筛候选，须人工复核）。平台架构与理论论证见 `01_方法说明/06_MOVECAT平台框架与理论设计.md`。

**写论文方法节**：`01_方法说明/` 五份文档即为"理论命题 → 操作规则"对应链的底稿（01 检索方法、02+03 图式提取操作化、04 量化指标、05 编码手册）；数据集构建过程引 `00_数据集说明与数据字典.md` §2 数据血缘。

## 5. 核心工作流（谁在哪一步做什么）

```
① 槽位确定（数据断层+功能验证）        ← 03_语料搭配「词频概览」
② 搭配词提取（每槽位前50，含logDice）   ← 「搭配明细」A–H 列（自动）
③ 图式初筛聚合（自动，未语义归类）      ← 06_图式提取结果（候选凸显图式+四图式得分）
④ 概念归类清洗（人工，语义标准）        ← 「搭配明细」I/J 列（人工填写）
⑤ 义位准入判定 Y/拓展/N（人工）         ← 02_义位标注「准入标签」列
⑥ PS = Mean_logDice × log2(N+1)      ← 「PS计算」表（J列填"保留"后自动）
⑦ 意象图式标注 四选一（人工）           ← 02_义位标注「意象图式」列（复核③的候选）/ 🏷️ 标注平台在线表单
⑧ 原型层级 → 英汉对齐 → 共享图式提取    ← 见 01_方法说明/05 第 4 节
⑨ 进度与仲裁（needs_review/存疑清单）    ← 标注平台指标 + oald_senses.human_reviewed
```

**分工原则**：② ③ ⑥ 为自动计算；④ ⑤ ⑦ 为人工判定；人工判定的主要依据是释义+例句（义位层），语料证据（纯净度、logDice、重心得分）为佐证——全部判定可回溯（05_原始数据）。③ 的候选结果按语义归类后重算即得 ⑦ 的量化依据。
