## 2. 构建流程（数据血缘）

```
步骤1 词表确定
  源：docs/词表义项清单.xlsx「词表概览」（Levin 1993 自移动词筛选收窄）
  产：136 动词 + 主范畴 + 次类 + 词目层意象图式初判
      → 04_汇总统计/verbs_136.json

步骤2 义项拆分（义位化）
  源：同 xlsx「义项明细」（OALD10 逐义项，132 词 665 条）
      + oxford-cache（dodder）+ levin-brief 研究者标注（scutter/kayak/oar）
  产：669 个义位，SenseID = 动词-Sn
      → 02_义位标注/<动词>_义项.xlsx（脚本 scripts/export_sense_annotation_sheets.py）
      → 02_义位标注/义位标注索引.xlsx

步骤3 语料检索（Sketch Engine API）
  参数：corpname=preloaded/ententen21_tt31, lpos=-v（3 词回退）, maxitems=50（另有一轮 15）,
        minfreq=auto, minscore=0, structured=1
  检索日期：2026-09-30；接口 bonito/run.cgi/wsketch
  产：逐词原始 JSON
      → 05_原始数据/wsketch_full/<动词>.json

步骤4 逐词语料档案生成
  产：每词 4 工作表（词频概览/搭配明细/图式证据/PS计算）
      → 03_语料搭配/<动词>.xlsx（脚本 scripts/export_verb_corpus_sheets.py）

步骤5 图式证据聚合（AI 初筛）
  方法：四类图式 × 证据槽位映射（《03 意象图式提取说明》2.1），
        逐词逐图式聚合覆盖槽位、搭配词数、Mean_logDice、重心得分 S
  产：→ 06_图式提取结果/图式提取结果汇总.xlsx
      → 06_图式提取结果/schema_evidence/<动词>.json
      （脚本 scripts/export_schema_extraction_results.py）

步骤6 跨词汇总
  产：→ 04_汇总统计/（检索汇总表、图式证据总览、汇总 JSON）

步骤7 打包整理（本 output 目录）+ 方法文档撰写（01_方法说明/）
```

**人工写入点**：全数据集仅两处人工区——② 义位标注表的图式/准入/理由/备注列（黄色底）、④ 语料档案的搭配明细 I/J 列（语义类别、保留/剔除）。其余全部由脚本从原始数据生成。

## 3. 数据字典

### 3.1 02_义位标注/<动词>_义项.xlsx

**工作表「义位标注」**（每词一行/义位）：

| 列 | 字段 | 类型 | 来源 | 说明 |
|---|---|---|---|---|
| A | SenseID | 文本 | 生成 | 动词-Sn，全数据集主键 |
| B | 词目 | 文本 | 词表 | 目标动词 |
| C | 义项序号 | 文本 | 生成 | S1, S2, …（词内连续） |
| D | 来源 | 文本 | 词表 | OALD10 / oxford-cache / levin-brief |
| E | 及物性 | 文本 | OALD 语法码 | intransitive / transitive / 两用 |
| F | 英文释义 | 文本 | OALD10 | 判定依据 |
| G | 例句 | 文本 | OALD10 | 换行分隔多条 |
| H | 句法模式 | 文本 | OALD 句式栏 | 166/669 已填（OALD 原生 162 + 补充词 4），其余人工补 |
| I | 是否习语 | 文本 | OALD | "是" = IDIOMS 组（173 条） |
| J | 原型义 | 文本 | OALD | "是" = 词典排序首位（≠ 研究 Y 类） |
| K | 原型主导义简述 | 文本 | 词表概览 | 词目层初判，仅作参考 |
| L | 意象图式 | 空（黄底） | **人工** | 四选一 |
| M | 准入标签 | 空（黄底） | **人工** | Y / 拓展 / N |
| N | 判定理由 | 空（黄底） | **人工** | 释义+例句依据 |
| O | 备注 | 空（黄底） | **人工** | 边界案例、图式叠加、编码分歧 |

**工作表「字段注释」**：14 字段定义原文（附录可直接粘贴）+ SenseID 规则 + 词表范畴信息。

### 3.2 03_语料搭配/<动词>.xlsx

**工作表 1「词频概览」**：语料库/平台/动词/词性/总频次/每百万词频次/槽位数/搭配词总数/检索日期；下半部分为槽位汇总（槽位名、槽位频次、槽位 logDice、搭配词数、前 5 搭配词）。

**工作表 2「搭配明细」**（核心，每行一个搭配词）：

| 列 | 字段 | 来源 | 说明 |
|---|---|---|---|
| A | 排名 | API | 槽位内按 logDice 降序 |
| B | 槽位（语法关系） | API | 嵌套槽位展开为 "槽位 > 子槽位" |
| C | 搭配词 | API | 词型（嵌套 PP 槽为子槽名，如 "%w" into ...） |
| D | logDice | API score | 搭配强度（见 04 方法文档） |
| E | 搭配频次 | API count | 共现形符数 |
| F | 典型组合(cm) | API | 典型词序组合 |
| G | cm频次 | API cmf | 组合形符数 |
| H | 语料库主题分布 | API High | 显著集中的主题及比值（前 3） |
| I | 语义类别（人工） | **人工** | 如：空间终点/抽象结果/方式副词/伪Theme |
| J | 处理（人工） | **人工** | 保留 / 剔除（PS 与图式重算的依据） |

**工作表 3「图式证据」**：四类图式 × 证据槽位逐行映射（图式、定义、槽位、槽位频次、搭配词数、前 5 证据）；空缺槽位 = 证据面缺失。

**工作表 4「PS计算」**：公式说明 + 自动汇总行（COUNTIF/SUMIF 引用搭配明细 J 列="保留"的行，算 N、logDice 总值、Mean、PS）。**填好 J 列后自动出数。**

### 3.3 06_图式提取结果/

**图式提取结果汇总.xlsx**：

- 「提取结果矩阵」（宽表，136 行）：动词、总频次、**候选凸显图式（AI初筛）**、四图式排序、四个重心得分 S；
- 「逐词逐图式明细」（长表，544 行 = 136×4）：动词、图式、覆盖槽位、覆盖率、搭配词数 N、Mean_logDice、重心得分 S、候选排名、Top3 证据；
- 「说明」：公式、定位与局限（必读）。

**schema_evidence/<动词>.json**（机器可读）：每词四图式的 coverage / n_types / mean_logdice / prominence_score / top_evidence（Top10，含槽位）/ slot_details（逐槽位频次与 logDice、Top5）。

**重心得分公式**：`S = Mean_logDice × log2(N+1)`，N 为该图式证据槽位去重搭配词型数。**定位为未语义归类的 AI 初筛**：候选凸显图式分布（方式伴随 118 / 终点抵达 10 / 互动位移 7 / 源点脱离 1）反映的是槽位覆盖与搭配强度的原始面貌，含多义噪声（如 reach 的抽象宾语计入终点抵达），**必须人工语义归类后重算**；规范化路径见 xlsx「说明」页与方法文档 03 §4。

### 3.5 05_原始数据/wsketch_full/<动词>.json

Sketch Engine wsketch 接口原始返回：Gramrels（槽位，含嵌套 PP 子槽）、Words（搭配词，含 count/score/cm/cmf/High 主题分布）、freq/relfreq、lpos、ws_status。**任何 xlsx 数值的最终溯源点。**
