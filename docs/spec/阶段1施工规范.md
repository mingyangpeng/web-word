## 1. 通用约定（全体遵守）

1. **DDL 自含**：新表一律在自己的模块里 `ensure_xxx_tables()` 幂等创建（参照
   `src/users_db.py: ensure_user_tables` 模式），**不改 `mysql_db.py` 的 CREATE_TABLES_SQL**；
   连接一律走 `src.mysql_db.get_db_cursor`，SQL 一律参数化；
2. **DDL 风格**：MySQL 8.0 / InnoDB / utf8mb4 / utf8mb4_unicode_ci，风格与
   `docs/p1/多人标注系统设计规范.md` §2 既有 DDL 一致；
3. **测试**：真 MySQL 用例按 `tests/test_users_db.py` 模式——连不上库整体 skip；
   每个 agent 只写自己的 `tests/test_<module>.py`（A 可扩展 `tests/test_users_db.py`）；
4. **输出安全**：任何用户生成内容出口过 `_html_escape`（本批为数据层，渲染留给批次 2）；
5. **零新依赖**：不修改 `requirements.txt`；
6. **风格**：模块 docstring 用中文写清「是什么/数据链/接口/降级」，与
   `src/semantic_search.py` 同风格；函数签名不得擅改（批次 2 页面层按签名接线）；
7. **验收**：自己的测试全过 ＋ 全仓库 `python -m pytest -q -p no:cacheprovider --no-cov`
   无回归（当前基线 610 passed）＋ 按报告格式交付。
