# 多人标注系统设计规范（唯一事实源 v1.0）

> 本文件是并行开发的契约。所有 agent 必须遵守本文件的表结构、模块签名、角色语义与安全规则。
> 需求决策（用户已拍板）：① 多人同时标注，管理员分配权限（GitHub 式：提交→审核→仲裁→定稿）；
> ② 所有标注任务支持多人；③ 双人/多人**都看同样 AI 草稿**（α 命名 = AI-assisted IAA）；
> ④ 标注员之间**互相不可见**对方提交（独立性），审核员/管理员可见全部。

## 1. 角色语义

| 角色 | 权限 |
|---|---|
| admin | 一切：用户管理、任务分配、快速通道（直写权威层）、仲裁、看全部 |
| reviewer | 看全部提交、看分歧清单、执行仲裁（定稿 gold）、不可管理用户 |
| annotator | 只看分配给自己的任务与 AI 草稿；提交/修改**自己的**标注；看不到他人提交 |
| viewer | 只读（统计、导出） |

## 2. 新增表 DDL（MySQL 8.0，风格与 mysql_db.py 既有 DDL 一致：InnoDB / utf8mb4 / 参数化查询）

```sql
CREATE TABLE IF NOT EXISTS users (
  id INT AUTO_INCREMENT PRIMARY KEY,
  username VARCHAR(50) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,          -- 格式 pbkdf2_sha256$iterations$salt_hex$hash_hex
  display_name VARCHAR(80) NOT NULL DEFAULT '',
  role ENUM('admin','reviewer','annotator','viewer') NOT NULL DEFAULT 'annotator',
  active TINYINT(1) NOT NULL DEFAULT 1,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS assignments (
  id INT AUTO_INCREMENT PRIMARY KEY,
  assignee_id INT NOT NULL,
  category VARCHAR(40) NOT NULL DEFAULT 'motion',
  task_type ENUM('admission','feature_coding','alignment') NOT NULL DEFAULT 'admission',
  scope_verbs JSON NULL,                        -- NULL=全部动词；否则 ["run","walk",...]
  status ENUM('open','in_progress','submitted','closed') NOT NULL DEFAULT 'open',
  assigned_by INT NOT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  KEY idx_assignee (assignee_id),
  CONSTRAINT fk_assign_user FOREIGN KEY (assignee_id) REFERENCES users(id),
  CONSTRAINT fk_assign_admin FOREIGN KEY (assigned_by) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS annotation_submissions (
  id INT AUTO_INCREMENT PRIMARY KEY,
  category VARCHAR(40) NOT NULL DEFAULT 'motion',
  sense_id INT NOT NULL,                        -- → oald_senses.id（996 义位含 4 补充）
  task_type ENUM('admission','feature_coding','alignment') NOT NULL DEFAULT 'admission',
  coder_id INT NOT NULL,
  payload JSON NOT NULL,                        -- admission 任务: {"admission":"Y|EXT|N","schema":"...","alignment":"...","cn_syntax":"...","strategy":"...","needs_review":bool}
                                                -- feature_coding 任务: {"features":{"P1":1,...}}
  ai_assisted TINYINT(1) NOT NULL DEFAULT 1,    -- 全员看同样 AI 草稿（用户决策③）
  status ENUM('submitted','adjudicated') NOT NULL DEFAULT 'submitted',
  submitted_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uq_submission (sense_id, task_type, coder_id),
  KEY idx_sense (sense_id), KEY idx_coder (coder_id),
  CONSTRAINT fk_sub_sense FOREIGN KEY (sense_id) REFERENCES oald_senses(id),
  CONSTRAINT fk_sub_coder FOREIGN KEY (coder_id) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS adjudications (
  id INT AUTO_INCREMENT PRIMARY KEY,
  sense_id INT NOT NULL,
  task_type ENUM('admission','feature_coding','alignment') NOT NULL DEFAULT 'admission',
  submission_ids JSON NOT NULL,                 -- 参与仲裁的提交 id 列表（留痕）
  adjudicator_id INT NOT NULL,
  gold_payload JSON NOT NULL,                   -- 定稿判定（同 payload 结构）
  note TEXT NULL,
  created_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uq_adjudication (sense_id, task_type),
  CONSTRAINT fk_adj_sense FOREIGN KEY (sense_id) REFERENCES oald_senses(id),
  CONSTRAINT fk_adj_user FOREIGN KEY (adjudicator_id) REFERENCES users(id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

CREATE TABLE IF NOT EXISTS reliability_runs (
  id INT AUTO_INCREMENT PRIMARY KEY,
  category VARCHAR(40) NOT NULL DEFAULT 'motion',
  task_type ENUM('admission','feature_coding','alignment') NOT NULL,
  n_coders INT NOT NULL, n_units INT NOT NULL,
  overall_alpha DECIMAL(5,3) NULL,
  per_feature JSON NULL,                        -- {"P1":0.82,...}（admission 任务为 {"admission":x,"schema":y,...}）
  disagreements JSON NULL,                      -- 分歧条目摘要
  computed_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;
```

## 6. 安全规则（全体遵守）

1. SQL 一律参数化（沿用 mysql_db.get_db_cursor 模式），禁止字符串拼接
2. 密码 pbkdf2_sha256 + 每用户随机盐（secrets.token_hex(16)），≥120000 迭代；禁止明文/可逆
3. 页面输出用户生成内容必须过 _html_escape
4. 权限检查在**函数入口**判定（role gate），不信任前端隐藏
5. 会话用 st.session_state["user"]，登出清除；不做 cookie 持久化（MVP）
6. 依赖新增仅允许：krippendorff（加入 requirements.txt）；PyYAML 已随 streamlit 可用

## 7. 验收标准（5 轮 review 的基准）

V1 登录/角色：未登录不能进标注页；annotator 看不到他人提交；reviewer 能看分歧不能管用户
V2 提交流：同一 (sense, task, coder) 重复提交=覆盖更新（UNIQUE 约束 upsert）
V3 分歧检测：两个编码人对同一 sense 的 admission 不同 → 出现在分歧清单
V4 α 正确性：用合成数据（已知 α）验证 compute_alpha；ordinal 与 nominal 分支各异
V5 范畴包：configs/motion 过 selfcheck；故意改错一项（如 evidence_slot 拼错）必须报错
V6 回归：pytest 现有套件全部通过
V7 AI 草稿可见性：annotator 表单页显示 LLM 初筛草稿（用户决策③）
