|---|---|---|

| 账号枚举防护 | 【已就绪】 | 无此用户/密码错/已停用统一 None；哑元哈希等成本（防时序枚举） |
| 内置 admin 弱口令 | 【挂账·运营前必做】 | bootstrap 凭据 admin/admin123 是公开的（代码注释里写着）——上线前**必须改密**（改后 is_using_default_password 翻 False）；新机部署流程应把「首登改密」写进运维手册 |
| SQL 注入 | 【已就绪】 | 全仓参数化（占位符）审计通过（批次 52 review）；LIKE 通配符转义（data_pages） |
