# 语料库意象图式提取方法说明

> 配套数据：`data/corpus/`（verb_sheets 逐词语料档案、sense_sheets 逐词义位标注表、图式证据总览.xlsx）
> 参照文档：`docs/开题报告.docx`（原型性量化分析——以到达类·终点抵达为例）、`docs/义项判定标准修改稿.docx`（义位编码标准）
> 语料库：Sketch Engine · English Web 2021 (enTenTen21) · Word Sketch（logDice）
> 用途：论文 4.1 方法节的理论-操作对应链说明；编码手册补充材料；图式标注操作规范

---

## 一、核心原理：图式不在语料里，语料里只有分布

意象图式是认知表征，语料库中可直接观察的只有**搭配分布**——哪个槽位被什么词填、频次多高、搭配强度多大。所谓"从语料提取图式"，实际是在 Talmy 位移事件框架的桥接下，把分布证据翻译为认知范畴：

- **理论桥接**：图式 = 位移事件要素（Theme / Source / Goal / Path / Manner / 互动关系）的凸显构型。源点脱离、终点抵达、方式伴随、互动位移四类图式，即四种不同的要素凸显方式（《义项判定标准修改稿》标准 2）。
- **分工**：语料回答"哪个要素在该动词的使用档案里信号最强、最同质"；词典释义回答"该要素是否为动词自编码"。两个信号叠加才产生图式标签，任何单一信号都不足以上升为结论。

## 二、槽位：句法层的证据面

### 2.1 定义

**槽位（slot）= 动词句法框架中由语法关系定义的空位**，填入的词为搭配词（filler）。术语来自配价语法/框架语义学的"槽-填"传统；Sketch Engine 官方术语为语法关系（grammatical relation, gramrel），本套数据中两者同指。

以 walk 为例：

```
[  man  ] walked [ slowly ] into [ the station ]
    ↑          ↑        ↑            ↑
 subjects   动词本体   modifiers   prepositional
  槽位                槽位          phrases 槽位
```

动词像一张带开口的框架，每个开口由**语法功能**（主语/宾语/方式状语/小品词/介词短语）定义，不由意义定义。语料库中所有真实例句填入同一开口的词，按搭配强度（logDice）排序，构成 Word Sketch 的一列。每词 xlsx「词频概览」下半部分的每一行就是一个槽位。

### 2.2 槽位的三个边界

1. **槽位 ≠ 论元**。subjects / objects 是论元槽（配价要求），modifiers / PP 多为附加语槽（可选）。此区分是"动词自编码 vs 句法增补"判定的基础：方式状语槽再活跃也只是附加语证据，不算动词编码了方式。
2. **槽位可条件细化**。`objects of "%w up"` 是"动词+小品词 up 后的宾语"复合槽位；`prepositional phrases` 下分 `"%w" into ...`、`"%w" to ...` 等子槽位。开题报告中 arrive 的 "X at ..." 与 "X in ..." 即并行子槽位，且经"数据断层 + 功能验证"论证不可合并（点状到达 vs 区域到达）——槽位精细化的现成范例。
3. **槽位 ≠ 语义功能**。同一语义功能可由不同槽位实现：arrive 的终点落在 PP 槽位（at/in），reach 的终点落在 objects 槽位。图式在语义层同一，槽位在句法层可以不同——这是开题报告"构式家族"（Goldberg 1995）把两变体拉入同一比较框架的依据。

### 2.3 槽位 → 语义角色的映射：三级结构

**"man 对应 Theme"的说法不成立**；正确的结构是三级：

| 层级 | 映射内容 | 性质 |
|---|---|---|
| 槽位 → 原型语义角色 | `subjects of 移动动词` 约束 Theme 候选 | 唯一配称"确定性"的一级，但也只是原型约束 |
| 搭配词 → 角色的类型样本 | subjects 槽高频词 man/dog/woman 归纳出 Theme 类型"有生实体（人/动物）" | 词型是 Theme 的**样本**，不是"man=Theme"的词典条目 |
| 具体 token → 角色 | 由构式 + SenseID 决定 | 须回到句子和义位 |

**反例一（槽位内噪声）**：walk 的 subjects 槽前 12 个搭配词为 minute, min, man, dog, woman, hour, girl, guy, people, mile, Jesus, someone——其中 minute/min/hour/mile 不是 Theme，来自 "five minutes' walk from the station" 名词性构式（walk 为动转名词）。槽位把此类构式一并捞入，故**槽位给出候选解读面后，必须经语义归类剔除伪 Theme**，才能进入 THEME 要素表征。

**反例二（槽位同、角色异）**：dog 在 objects of "walk" 槽（walk the dog）不是 Goal，而是**使役移动体**（对应 walk-S4 "make an animal walk" 义位）；man 在 objects of "chase" 槽是被追踪互动方。同槽不同角色，须由义位语境裁决。

**操作结论**：读「图式证据」表时，不得直接引用槽位原始搭配词列表；先语义归类（搭配明细 I/J 列），再归纳要素类型。这正是开题报告把概念归类放在图式要素表征之前的原因。

## 三、意象图式提取四步法

### 3.1 槽位 → 事件要素证据面映射表

| 图式（语义重心） | 证据槽位 | 理由 |
|---|---|---|
| 源点脱离 | particles after（away/off/out）；objects of "%w off/out/away"；from/out of 类 PP | away/off/out 是英语编码"离开源点"路径的专职小品词，其宾语即被脱离物 |
| 终点抵达 | objects of "%w"；objects of "%w up/down/in/into"；to/at/in 类 PP；particles after with object | GOAL 在及物动词落为宾语（reach the summit），不及物动词落为趋向 PP（arrive at） |
| 方式伴随 | modifiers（方式状语）；adjectives after；"%w" and/or ...（并列同类方式动词）；subjects（典型运动体）；usage patterns | 方式不改变论元结构，落在状语修饰与同类方式动词并列；主语给出运动体类型 |
| 互动位移 | objects / pronominal objects；pronominal subjects；after/behind 类 PP；particles after with object | 互动必有第二实体，落为宾语或追踪/伴随介词补足语 |

**注意**：objects 与 prepositional phrases 同时出现在"终点抵达"与"互动位移"下，subjects 同时出现在"方式伴随"与"互动位移"下——槽位重合是设计使然。同一搭配面在不同义位下激活不同图式（reach the summit 是终点，follow him 是互动）；映射给的是"去哪找证据"，不是"证据指向哪个图式"。

### 3.2 搭配词语义归类（人机分工接口）

同一 Goal 证据，station（空间终点）激活空间位移图式，conclusion（抽象结果）不激活。语义归类标准（以"到达类"为例，开题报告原文）：

- **保留**：能明确指代可被物理到达的三维空间实体的搭配词（destination, airport, station, summit, shore…）；
- **剔除**：抽象概念名词（conclusion, agreement, goal, level）、隐喻投射名词（milestone, threshold）、量化/时间/状态名词（number, time, speed）。

剔除记录完整保留、写明理由（方法透明度与审稿核查要求）。

### 3.3 重心计算

两个指标：

- **纯净度**：某图式一致搭配词占槽位前 15/50 的比例；
- **强度×广度**：一致搭配词的 logDice 均值 × 数量（即 PS 公式构件）。

**判定规则**：某图式的证据面既覆盖主要槽位、搭配词又语义同质 → 该图式凸显；证据面缺失或搭配词语义发散 → 该图式非重心。

### 3.4 释义回验（动词自编码 vs 句法增补）

《修改稿》标准 2 硬约束：依据动词义位本身编码的语义重心判定，**不纳入句子状语带来的附加语义**。limp 释义 "to walk with difficulty because one leg is injured"——跛行方式在词根内 → 方式伴随图式；walk 释义 "move on foot"——方式（用脚）在词根内，Goal 不在论元结构 → 方式伴随。语料回答"要素多常见"，释义回答"要素是否动词自带"。

### 3.5 实例一：walk（真实数据）

- subjects：man, dog, woman, girl, guy, people——Theme 全为有生移动者，信号强且同质（minute/min/hour/mile 为名词构式噪声，归类时剔除）；
- modifiers：slowly, barefoot, alone, briskly, backwards——Manner 信号强且同质；
- objects：distance, tour, trail, mile——多为名词化用法（a walking tour），非动词的 Goal 论元；
- PP：into(3.9), to(3.8), in(3.74)——路径全靠可选介词短语增补，动词本体不带。

归纳：方式与运动体信号内嵌且同质，Goal 依赖外部增补且不进入论元结构，释义印证 → **方式伴随图式**。

### 3.6 实例二：arrive / reach（开题报告数据）

- arrive：at/in 槽位空间终点占比 80%–87%，N=60，Mean logDice=7.291，PS=43.23 → GOAL 高度锚定，**终点抵达图式**，原型成员；
- reach：objects 槽位空间词仅约 20%（height, peak, destination, top），N=25，Mean logDice=6.459，PS=30.36 → GOAL 锚定弱，**终点抵达图式**，典型成员（垂直维度终点为显著次类）。

两词图式相同的证据是其槽位剖面完全不同——这就是"提取"的实际含义：**槽位分布剖面的差异投射为图式锚定强度与原型地位的差异**。

## 四、图式重心指数（量化方案）

PS 回答范畴层"谁最典型"；同一公式换个方向可回答动词层"该词凸显哪个图式"：

```
S(图式) = Σ over 该图式证据槽位 ( 语义归类=一致的搭配词数 ) × 平均 logDice
```

- 取 argmax 为凸显图式；次高记入备注（对应 14 字段规范"多重图式取凸显重心，次要图式记入备注"）。
- **前提**：先完成语义归类（I/J 列）；严格义位级提取须按 SenseID 筛出与目标义位一致的搭配词再算（Word Sketch 为词目层数据，多义动词如 run 的计算机义搭配会稀释图式信号）。
- 指数是**证据**不是**结论**：最终标签须能被释义+例句回溯（《修改稿》可回溯性要求）；边界案例进争议清单人工仲裁。

## 五、logDice 计算与义位筛选的顺序

**logDice 数值本身与义位筛选无关**：Sketch Engine 的 Word Sketch 不做词义消歧，搭配强度是词目层、全义位聚合后一次性算出；筛选改变的是**哪些搭配词进入 PS**，不是 logDice 本身。

| 顺序 | 得到什么 | 风险/适用 |
|---|---|---|
| 筛选前算（词目全部搭配词） | 动词在范畴构式中的整体词汇代表性（词目层原型排序） | 多义污染：reach objects 槽前 15 个中 12 个抽象名词，不过滤会把"达成协议"的搭配强度混入"空间到达"原型性 |
| 筛选后算（仅保留与 Y 类义位一致搭配词） | 义位层原型性，与《修改稿》"分析单元是义位"一致 | 需人工语义归类；归类标准必须独立于 logDice（语义标准，否则循环） |

**推荐顺序**（开题报告实际采用）：义位准入判定（定性）→ 概念归类（清洗）→ PS 计算（定量）。逻辑链为"准入划定样本边界 → PS 在边界内排序"。同时**报告筛选前纯净度**（arrive 80% vs reach 20%）作为独立证据（开题报告表 19 的做法）。

严格意义上的"义位级 logDice"在此套 Word Sketch 数据中不可得（多义搭配混合，概念归类只是"与目标义位一致用法"的代理筛选）；若必需，须用 CQL 语义限定跑 concordance，成本高且一般不必——开题报告的构式家族思路（arrive 的 PP 槽位 ≈ reach 的 NP 槽位）本身即绕开该问题的设计。

论文表述建议（一句话）："清洗以义位语义标准进行、PS 在清洗后集合上计算、筛选前纯净度另行报告。"

## 七、操作顺序总览

```
词表（136 动词，Levin 样本池）
   │
   ├─ 义位拆分 ──→ sense_sheets（SenseID = 动词-Sn）
   │
   ├─ 义位准入判定（标准1：Y/拓展/N）← 释义 + 例句（主要依据）
   │                                   ← 语料纯净度（佐证）
   │
   ├─ 概念归类清洗 ──→ 搭配明细 I/J 列（语义标准，独立于 logDice）
   │
   ├─ PS 计算（范畴内原型/典型/边缘排序）
   │
   ├─ 图式重心判定（标准2：四选一）← 释义自编码要素（主要依据）
   │                                ← 图式证据槽位 + 纯净度/重心指数（佐证）
   │
   └─ 原型成员典型搭配 → 共享认知图式提取 → 三域七系 → 多维释义模板
```

每一步判定可回溯：标签 ← 释义/例句 + 语料数据（wsketch_full 原始 JSON）。
