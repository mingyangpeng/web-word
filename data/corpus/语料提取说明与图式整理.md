# 136 个英语自移移动动词语料信息提取说明

> 数据来源：Sketch Engine（广外图书馆 libVPN 代理访问）
> 语料库：English Web 2021 (enTenTen21，约 61 亿词)
> 检索接口：`bonito/run.cgi/wsketch`（Word Sketch 结构化 JSON）
> 检索日期：2026-09-30
> 词性限定：`lpos=-v`（动词）；kayak / skateboard / backpack 三词动词 sketch 不存在，回退为不限词性（名词主导）

> 用途：本文件为**数据字段与操作说明**；方法论论证（槽位定义、槽位→角色三级映射、图式提取四步法、图式重心指数、logDice 与义位筛选顺序）见配套文档 **《图式提取方法说明.md》**（同目录）。

## 二、每词 xlsx 的四个工作表

### 1. 词频概览

| 字段 | 说明 |
|---|---|
| 语料库总频次 | 该动词（动词词性）在 enTenTen21 的形符总数 |
| 每百万词频次 (relfreq) | 标准化频率，跨词可比 |
| 语法关系（槽位）数 | Word Sketch 返回的语法关系列数（如 27 个） |
| 搭配词总数 | 每槽位前 50 个搭配词的合计 |

下半部分是**槽位汇总表**：每个语法关系（槽位）的频次、槽位 logDice、搭配词数、前 5 搭配词及其 logDice。

### 2. 搭配明细（核心工作表）

每行一个搭配词，字段与开题报告「表 7-9」对齐：

| 列 | 字段 | 来源/说明 |
|---|---|---|
| A | 排名 | 槽位内按 logDice 降序的排名 |
| B | 槽位（语法关系） | 如 `modifiers of "%w"`、`objects of "%w"`、`particles after "%w"`；嵌套槽位（介词短语）展开为 `prepositional phrases > "%w" into ...` |
| C | 搭配词 | Sketch Engine 返回的搭配词形 |
| D | logDice | 搭配强度（Sketch Engine 默认指标，理论上限约 14，跨槽位跨词可比） |
| E | 搭配频次 | 该搭配在语料库中的共现形符数 |
| F | 典型组合 (cm) | 搭配的典型词序组合（如 `walked slowly`） |
| G | cm 频次 | 典型组合的形符数 |
| H | 语料库主题分布 | 该搭配显著集中的语料库主题（topic/genre）及比值，如 `especially pets & animals(225.5)` |
| I | 语义类别（人工） | **留空**，供概念归类填写（如「空间终点」「抽象结果」「方式副词」） |
| J | 处理（人工） | **留空**，供数据清洗填写（「保留」/「剔除」） |

I、J 两列即开题报告「概念归类与数据清洗」步骤的落点：以「是否明确编码或指义位准入所要求的事件要素」为判定标准，将搭配词归入语义类别，核心槽位中与范畴图式一致的标「保留」。

### 3. 图式证据

自动按**四类意象图式**（义项判定标准修改稿）汇总对应证据槽位的搭配：

| 意象图式 | 定义 | 证据槽位 |
|---|---|---|
| 源点脱离图式 | 重心为运动体离开起始位置（leave, depart 类） | particles after（away/off/out）、objects of "%w away/off/out"、prepositional phrases（from/out of） |
| 终点抵达图式 | 重心为运动体到达目标位置（arrive, reach 类） | objects of "%w"（终点宾语）、objects of "%w up/down/in/into"、prepositional phrases（to/at/in）、particles after with object |
| 方式伴随图式 | 重心为位移过程伴随的运动方式（run, swim, limp 类） | modifiers（方式状语）、adjectives after、usage patterns、subjects（典型运动体）、"%w" and/or（并列同类方式动词）、complements |
| 互动位移图式 | 重心为两实体同时位移、空间互动（chase, follow 类） | objects（互动对象宾语）、pronominal objects/subjects、prepositional phrases（after/behind）、particles after with object |

每个图式列出：证据槽位、槽位频次、搭配词数、前 5 搭配证据（含 logDice）。**空缺槽位 = 该动词在该图式维度语料证据不足**。最终图式标签需结合 OALD 释义与真实例句人工判定，本表提供的是数据证据面。

### 4. PS 计算

原型性得分工作表，公式（与开题报告一致）：

```
PS = Mean_logDice × log2(N + 1)
```

- **Mean_logDice**：所有「处理=保留」搭配词 logDice 的算术平均（质量维度）
- **N**：「处理=保留」搭配词总数（广度维度，对数压缩）

操作流程（对应开题报告四步法）：

1. **槽位确定**：从「词频概览」的槽位汇总中，依据数据断层（logDice 断崖）与功能验证（不可互相替代的独立构式都保留）锁定该动词编码范畴核心语义的槽位；
2. **搭配词提取**：搭配明细表已按槽位列出前 50 搭配词；
3. **概念归类**：在 I 列填写语义类别、J 列标「保留/剔除」（剔除记录完整保留，写明理由，供方法透明度核查）；
4. **PS 计算**：工作表内置 `COUNTIF`/`SUMIF` 公式，自动汇总 J 列为「保留」的行数（N）与 logDice 总值，算出 Mean 与 PS。

## 三、与开题报告例子的字段对应

开题报告「原型性量化分析——以到达类·终点抵达次范畴为例」的表 7-9（arrive/reach 搭配清洗表）字段：排名、搭配词、logDice、语义类别、处理 —— 即本套 xlsx「搭配明细」表的 A/C/D/I/J 列。表 13-14（槽位汇总）对应「词式概览」下半部分；表 15（PS 对比）对应「PS计算」表。

## 四、注意事项

1. **logDice 与 score**：Sketch Engine Word Sketch 的 `score` 字段即 logDice（Kilgarriff et al. 2014），无需换算。
2. **嵌套槽位**：`prepositional phrases` 槽位下是二级槽位（`"%w" into ...` 等），其 count/score 即该介词与动词的共现频次与 logDice，搭配明细表已展开。
3. **三个回退词**：kayak、skateboard、backpack 的动词 sketch 在 enTenTen21 不存在（动词用法语料不足），xlsx 使用不限词性的数据，词性栏标注实际 lpos；后续义位分析时这三个词的动词用法证据较弱。
4. **maxitems=50**：每槽位取前 50 搭配词（开题报告例子用前 15/20）；若需复现例子的口径，在搭配明细表取前 15 行即可。
5. **可回溯性**：每词原始 JSON（`wsketch_full/`）完整保存，任何 xlsx 数值均可回溯到 API 原始返回。

## 五、图式提取操作链（衔接后续分析）

```
逐词 xlsx（本套数据）
   │
   ├─ 槽位确定 ──→ 词频概览（数据断层 + 功能验证）
   ├─ 概念归类 ──→ 搭配明细 I/J 列（人工，参照义项判定标准）
   ├─ PS 计算 ───→ PS计算表（自动公式）→ 范畴内原型/典型/边缘成员排序
   │
   └─ 图式证据 ──→ 图式证据表（四类图式 × 证据槽位）
                      │
                      ▼
        结合 OALD 释义 + 真实例句 → 义位准入（Y/拓展/N）
                      │
                      ▼
        原型成员典型搭配 → 共享认知图式提取（三步操作法）
                      │
                      ▼
        三域七系范畴体系 → 多维释义模板（释同辨异）
```

### 逐词矩阵的读法

「逐词图式证据矩阵」表每行一个动词，四列槽位覆盖（如 `5/5`）+ 四列最强证据（该图式下 logDice 最高的搭配词）。用法：

1. **图式倾向初判**：槽位覆盖比例高 + 最强证据语义类别匹配 → 该图式为该词的候选凸显图式（最终以 OALD 释义 + 例句人工判定为准）；
2. **范畴聚类入口**：按「方式伴随」覆盖排序可快速圈出方式聚焦动词（83 词全覆盖）；「源点脱离」全覆盖的 24 词（charge, dart, dash, run, scoot, sweep, tear, drift, drop, float 等）即脱离类候选；
3. **搭配证据聚合**：「图式聚合证据」表给出每图式跨 136 词的 Top20 搭配（logDice 最大值），可直接用于共享认知图式的事件要素表征（THEME/MOTION/GOAL/SOURCE）。

### 聚合证据要点（Top 搭配，logDice）

- **源点脱离**：`"%w" from ...(28.8)`、`through(21.7)`、`out/off` 小品词、`door(12.6)`、`job(12.2)`（walk out the door / quit a job 类脱离场景）；
- **终点抵达**：`to/at/in/into` 介词短语、`street(12.4)`、`river(12.1)`、`sleeve(13.3)`（roll up one's sleeve 类）——注意 `objects of "%w"` 槽位混杂抽象宾语（process, price, cost），概念归类时需剔除；
- **方式伴随**：并列动词槽（`trot(12.4)`、`canter(12.4)`、`trudge(11.9)`、`slog(11.6)`）与方式副词（`crazy(12.7)`、`drag(12.6)`）——并列动词本身即方式聚焦的直接证据；
- **互动位移**：代词宾语/主语槽（`pronominal objects` 65 词）与 `after/behind` 类介词短语是互动关系的主要证据面。

### 与开题报告「到达类」例子的衔接

开题报告以 arrive/reach 演示的「槽位确定→搭配提取→概念归类→PS 计算」四步法，本套数据已将前三步的原始材料按词备齐（arrive、reach 不在 136 自移移动词清单内，但同流程适用于清单内全部动词；终点抵达图式的证据槽位即 objects of "%w" + prepositional phrases to/at/in，与例子中 X at ... / X in ... / objects of X 完全对应）。


## 七、义位标注表（SenseID 体系）

配套文件：
- `data/corpus/sense_sheets/<动词>_义项.xlsx` —— 136 个逐词义位标注表（每词两个工作表）
- `data/corpus/义位标注索引.xlsx` —— 全部义位的索引（动词 × 义位数 × SenseID 范围 × 语料频次 × 词表范畴）

### 数据规模

- **669 个义位**，覆盖 136 词（OALD10 逐义项数据，来自《词表义项清单.xlsx》义项明细，132 词 665 义位）
- 4 个缺义词补充：dodder（Oxford 缓存）、scutter / kayak / oar（levin-brief 研究者标注，释义栏已注明「OALD10 未收录」）

### 义位编号体系

```
SenseID = <动词>-S<序号>
例：walk-S1, walk-S2, ..., walk-S24
```

**后续所有分析均以 SenseID 为单元**：
1. 义位准入判定（Y / 拓展 / N）—— 逐 SenseID 判定；
2. 意象图式标注（四选一）—— 逐 SenseID 标注；
3. 语料搭配证据 —— verb_sheets 的图式证据槽位与 SenseID 对应（同一动词的全部义位共享该词的 Word Sketch 数据，概念归类时按 SenseID 的语义类别清洗搭配词）；
4. PS 计算 —— 在 SenseID 准入为 Y 的基础上，以该义位对应的核心槽位搭配计算。

### 义位标注表字段（14 字段 + SenseID）

| 字段 | 填写状态 | 说明 |
|---|---|---|
| SenseID | 已填 | `<动词>-S<序号>` |
| 词目 / 义项序号 / 来源 | 已填 | OALD10（4 个缺义词为 oxford-cache / levin-brief） |
| 及物性 | 已填 | OALD 语法码（intransitive / transitive / 两用） |
| 英文释义 / 例句 | 已填 | 判定依据与语义证据 |
| 句法模式 | 部分填（162/665） | OALD 句式栏，缺失处需人工补 |
| 是否习语 / 原型义 | 已填 | IDIOMS 组 173 条已标记 |
| 原型主导义简述 | 已填 | 词表概览的研究者概括 |
| **意象图式** | **留空（黄色底）** | 人工标注，四选一，多重图式取凸显重心、次要记备注 |
| **准入标签** | **留空（黄色底）** | Y / 拓展 / N |
| **判定理由** | **留空（黄色底）** | 释义+例句依据，供编码信度复核 |
| **备注** | **留空（黄色底）** | 边界案例、图式叠加、编码分歧 |

黄色底四列即人工标注工作区；「字段注释」工作表为附录可直接粘贴的 14 字段定义。
